# Personal Resume Website

A clean, professional personal resume website hosted on GitHub Pages.

**Live Site:** https://twinkleyang1.github.io/

## Tech Stack

- Pure HTML5 + CSS3 (no build required)
- GitHub Pages (free hosting)
- Responsive design

## Development

Simply open `index.html` in a browser, or use any static file server:

```bash
python -m http.server 8000
```

## Deployment

The site auto-deploys from the `main` branch via GitHub Pages.
